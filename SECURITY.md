# Security Policy

## Reporting a vulnerability

Please don't open a public issue for security problems.

Report them privately through GitHub's private vulnerability reporting: go to the repository's **Security** tab and choose **Report a vulnerability**, or use this link:

https://github.com/Ali-Parandeh/production-readiness-auditor/security/advisories/new

Useful things to include: what you found, how to reproduce it, and what impact you think it has. Examples of what counts here would be instructions in `SKILL.md` or the reference files that could lead Claude to leak repository contents, follow injected instructions, or take actions the user didn't ask for.

## What to expect

You should get an acknowledgement within 5 working days. Confirmed issues are fixed in a new release, and reporters are credited unless they'd rather not be.

## Supported versions

Only the latest release is supported.
